# Security policy

Report vulnerabilities, exposed credentials, or private data through a [private GitHub security advisory](https://github.com/Maciexx/auditing-seo-geo-ai-search/security/advisories/new). Do not open a public issue for a vulnerability, credential, or private data.

Include the affected version or commit, a short impact description, steps to reproduce, and any suggested mitigation. Remove secrets and unrelated personal data from the report.

Repository fixtures must be synthetic. Live evidence, authenticated data, screenshots, and client evidence must stay outside the repository.
